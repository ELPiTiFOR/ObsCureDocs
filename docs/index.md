# Welcome to ObsCure Docs

This is a collaborative documentation for the ObsCure franchise. Here you will
find information on how the games work and their file formats, which will be
very important to make tools or mods for them.

If you want to learn how to make mods or tools for ObsCure, start by reading
the next page, the [Introduction](intro.md).

If you want to participate in completing this documentation, take a look at the
[How to collaborate](#how-to-collaborate) section below.

## How to collaborate
Everyone is encouraged to share their own discoveries, if you want to do so you
should check the repository of this site by visiting
[this link](https://github.com/ELPiTiFOR/ObsCureDocs), then fork it, clone it,
modify it, and finally make a pull request with your changes. The PR will then
be checked and merged into the main branch if everything is correct. Thank you
to all the contributors that have worked and/or will work on this project!
